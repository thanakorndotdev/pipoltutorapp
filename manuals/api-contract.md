# API contract — SoW 2026

Contract date: 2026-11-14 (regenerated 20:17 +07, 163 mounted routes). Production browser prefix is `/api`; the Elysia paths below omit it. `api-contract.json` exports the mounted request schemas (body, query, params), generated with `bun run scripts/export-contract.ts` from `backend/app`. Routes without an explicit response schema have `response: null`; their response shapes and privacy rules are described here and exercised by the integration scripts. This export is not a complete OpenAPI specification.

## Authentication, permission and errors

- `pt_session`: HttpOnly, SameSite=Lax session linked to the server's Google subject. Browser-supplied email/user ID is never authentication. Every request reloads the user's role and deletion status. Google OAuth uses the existing `/auth/google` and callback flow.
- `x-admin-key`: Owner-controlled tooling credential, server-configured. Never place it in frontend source, public URLs or exported collections. The admin gate stores an explicitly entered key in tab-scoped sessionStorage only.
- Roles: Owner, Admin, Author, Moderator, Results Viewer; custom module grants `read`, `write`, `publish`, `export`. Module names: exam, certificate, ranking, article, comment, daily, audit, users, site. Owner alone changes permissions and signing keys. Author edits their own drafts and submits for review; publishing requires a separate grant.
- Success JSON uses the named resource, e.g. `{article}`, `{attempt}`, `{comments}`; binary responses have PNG/PDF/CSV MIME types. Standard domain errors: `{error:string}`. Unexpected errors: `{error,requestId}` without internal details. HTTP 401 unauthenticated, 403 denied/origin, 404 absent or another user's object, 409 stale version/duplicate/closed action, 410 removed published article, 415 invalid media, 422 invalid input, 429 rate limit, 500 internal error.
- All writes with an Origin header check it against the configured public/request origin. Production must run behind the supplied Caddy HTTPS configuration with a correct `PUBLIC_URL_DOCKER`. No-store applies to authenticated JSON and original certificate downloads.
- Preview records bind actor, module, target, payload digest and source version; expire after 15 minutes and commit once within a transaction. Reusing a consumed preview returns 409. After 409 reload and preview again; do not silently replay a changed import.

## Main interfaces

| Method and path | Request | Response / privacy |
|---|---|---|
| GET `/attempts`, `/attempts/:id` | session, owned ID | Own attempts only. The list includes the pack `level` (m1/m4/null) and `subjectLabel`. Finished scores use the selected published official value; hidden metrics return null. Non-selected attempts link to the selected ranking through the ranking card. Raw scores remain in restricted admin results. |
| POST `/attempts/:id/heartbeat` | session | `{ok:true}`; server checkpoints accepted active time. Offline/unverified gaps are flagged for audited time review. |
| POST `/attempts/:id/activity/streams` | session, owned in-progress attempt; `{clientId: uuid}` | `{stream}`. Idempotent per browser client ID; at most 16 streams per attempt (429). A second stream marks the attempt's time unverified. |
| PUT `/attempts/:id/activity/:streamId` | session; `{sequence, elapsedMs, activeMs, offlineMs}` (integers, ms) | `{sequence, duplicate, requiresReview:true}`. Sequence must be previous+1; identical replay returns `duplicate:true`, a changed replay 409. Totals are monotonic, `offline <= active <= elapsed`, capped by the server-recorded end (submit/expiry). Evidence closes 24 h after the attempt ends or once reviewed. Browser-reported time is evidence only; it never changes the trusted ranking duration automatically. |
| GET `/admin/ranking/:packId/activity/:attemptId` | ranking.read | Attempt time fields, every stream with checkpoints and server receipt times, `maxActiveSeconds`, `version`. |
| POST `/admin/ranking/:packId/time/preview`, PUT `/admin/ranking/:packId/time` | ranking.write; `{attemptId, activeSeconds, reason}` then `{previewId}` | Finished attempts only; `activeSeconds <= maxActiveSeconds`. Commit sets verified active time, freezes further evidence, audits `ranking.time_review` with the evidence version, and recalculates ranking. Stale evidence version returns 409. |
| GET `/attempts/:id/ranking` | session | `{status,version,nRank,nRef,selectedAttemptId,metrics,needsReview,note,statisticalNote,zeroSd}`. Only visible own official metrics; never other names, exclusions or flags. |
| GET `/certificates` | session | Own certificate revisions, default selection and private download links. |
| GET `/certificates/:id/file?format=png\|pdf` | owner session or granted admin | Stable original file; 409 while queued; private/no-store. Another student receives 404. |
| GET `/cert/:publicId` | public | Status, signature validity and non-personal exam/template metadata. No email, name, score or attempt ID. |
| POST `/cert/:publicId/verify-name` | `{name}` | `{match:boolean}`; first, surname or full printed name after whitespace/Unicode normalization. 8 checks per client/certificate/minute. Does not reveal the name. |
| GET `/admin/ranking/:packId` | ranking.read; optional `q,flag` | Current calculated/official snapshot and up to 100 revisions. Restricted participant identifiers and flags. |
| PUT `/admin/ranking/:packId/settings` | policy, visibility[], publishedFinal, suspiciousSeconds, baseVersion, reason | Appends a revision. Final publication also requires publish. Selection policy is locked after final publication. |
| POST `/admin/ranking/:packId/preview` | changes[] with userId, optional attemptId/included/metrics/clearMetrics, reason | previewId, expiry, changes, aggregate before/after, warnings. No raw answer mutations. |
| POST `/admin/ranking/:packId/import` | multipart file CSV/XLSX | Validates IDs, matching exam, duplicates, finite/ranged numbers and reasons; preview with before/after/diff. Max 3MB / 5,000 rows. |
| POST `/admin/ranking/:packId/commit` | `{previewId}` | New version and immutable snapshot; all-or-nothing. |
| GET `/admin/ranking/:packId/export` | ranking.export | Formula-neutralized UTF-8 CSV. |
| POST `/admin/ranking/:packId/rollback` | versionId, baseVersion, reason | New revision referencing the restored revision; original history survives. |
| GET `/articles` | public; q,kind,level,subject,category,from,to,offset,limit | Published frozen cards, categories and search suggestions. limit <=100, offset <=10,000; internal candidate ceiling 5,000 articles. Thai token/fuzzy search and Owner synonyms; reassess search engine above this size. |
| GET `/articles/:slug` | public | Frozen published content; 301 alias, 404 draft/archive, 410 deleted published content. |
| POST `/articles/:slug/event` | kind view/click_in/click_out; optional referrer | `{ok}`. Cookie-based visitor/day/kind deduplication; stores hostname only, not full referrer. Not a unique-human count. |
| GET/POST `/articles/:slug/comments` | read public; write session `{text,parentId?}` | Public published comments only. Flagged/spam comments stay hidden; max 5 writes/user/minute. |
| POST `/admin/articles`, PUT `/admin/articles/:id` | article.write, content and baseRevision | Draft/revision. Runtime structured block validation rejects unsafe HTML/URLs/embed domains. Public snapshot remains unchanged until approval/publish. |
| POST `/admin/articles/:id/workflow` | action, baseRevision, scheduledAt? | submit/approve/schedule/publish/archive/delete/restore. Scheduling requires approval and a future instant. |
| GET `/admin/cms`, POST/PUT/DELETE `/admin/cms/categories...` | article grants | Taxonomy, synonyms, moderation, homepage configuration and analytics. Empty-only delete; merge preview/commit moves articles and preserves old category aliases. Cycles rejected. |
| PUT `/admin/comments/:id` | comment.write, action, reason | approve/reject/hide/delete/reply; audit and once-only reply notification. |
| GET `/notifications`, POST `/notifications/:id/dismiss` | session, owned ID | Own undismissed messages; dismissal is persisted. |
| GET `/daily/today`, `/daily/archive` | public intro; private progress requires session | Bangkok date snapshot plus `extendedUntil` (this learner's active extension of the day) and `pastExtension: {date, until} \| null` (yesterday still open for this learner). Answers withheld until configured reveal policy and while any extension of that day is active. Archive practice never changes Fire; an extended day is absent from the archive until its window closes. |
| GET `/daily/archive/:date` | public; session for extended days | Past day view. During an active extension: the covered learner gets an answerable view (`archive:false`), others 404. Practice POST returns 404 for an extended day. |
| POST `/daily/submit` | session; date, questionId, answer `{selectedChoices,textAnswer}`, requestId UUID | Correct/try/hint and fresh view of the submitted date. Two attempts/question, server cutoff (23:59:59 Bangkok, or an approved extension covering this learner), per-user/day lock, request deduplication. Third/future/stale submissions rejected. |
| GET `/daily/fire`, POST `/daily/recover` | session | Own current/highest/pendingDeadline/monthly quota; recovery only next Bangkok day. |
| POST `/admin/daily/import`, `/import/commit` | daily.write, CSV/XLSX+reason then previewId | Strict template, preview, atomic grouped challenges. Empty/malformed rows reject the complete file. |
| POST `/admin/daily/:id/preview`, `/:id/commit` | content, keepFire, resetTries, reason | Preview effect; historical verdicts and revisions retained. Existing assigned dates cannot move. |
| POST `/admin/daily/outage/preview`, `/outage/commit` | from/to, userIds[], mode, reason, `until` (extend only) then previewId | protect/compensate/bulk_recover write ledger days and never consume user recovery quota. `extend` keeps today's challenge open until `until`: from = to = today (Bangkok), `close < until <= close + 24 h`, empty userIds = every learner. Commit re-checks that it is still today and `until` is in the future (409 otherwise), stores a `daily_extensions` row and audits `daily.extend`. Past days cannot be extended because their keys are already revealed. |
| GET `/admin/audit`, `/errors`, `/retention` | audit.read | Restricted history/errors/policy proposals. Audit limit 100 + offset; errors latest 200. `/retention` adds `automaticDeletion: ["technical_logs","learning_events"]`. |
| PUT `/admin/retention/:category` | Owner; days or null, baseVersion, reason | Policy approval/version/audit. Once approved, the backend hourly deletes `error_logs` (technical_logs) and `article_events` (learning_events) older than the period and audits `retention.purge` as system. Other categories are recorded only; see lifecycle plan in operations guide. |
| PUT `/admin/users/:id/permissions` | Owner; staffRole,modulePermissions,reason | Current-session revocation on next request; last Owner cannot be removed. |
| POST `/profile/delete` | own session; certificatePolicy keep/revoke, consent:true, confirmation | Consent record, tombstone profile, anonymized attempt identity, deleted comments and revoked sessions. Certificates follow the explicit choice. |
| POST `/admin/media/attachments` | granted writer, file | Validated PDF/Office forced-download URL; public article attachments only. Original certificate storage is separate and private. |

Certificate templates, publish, key rotation, pack eligibility and queue retry retain the existing `/admin/cert-templates` and `/admin/certificates` contracts; exact request schemas are in the generated export. CSV examples are under `samples/` and are fixtures, not real account identifiers.
