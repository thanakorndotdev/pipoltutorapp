# คู่มือผู้เรียนและผู้ดูแล — ส่วนเพิ่ม SoW 2026

## ผู้เรียน

เข้าด้วย Google บัญชีที่ใช้ทำข้อสอบ เมนูบัญชีมี Dashboard, โปรไฟล์, ประวัติข้อสอบ, เกียรติบัตร, โจทย์วันนี้ และออกจากระบบ มือถือเปิดเมนูมุมขวาเพื่อเข้าทั้งเจ็ดหมวดหลัก

**เวลาทำข้อสอบ:** ระหว่างสอบเบราว์เซอร์ส่งบันทึกเวลาทำงานไปที่ server เป็นระยะ ถ้าหลุดอินเทอร์เน็ต บันทึกจะเก็บในเครื่องและส่งตามเมื่อกลับมาออนไลน์ ให้ทำข้อสอบในแท็บเดียว การเปิดหลายแท็บหรือหลุดการเชื่อมต่อทำให้เวลาของครั้งนั้นต้องให้ผู้ดูแลตรวจรับก่อนใช้เรียงอันดับเมื่อคะแนนเท่ากัน

**ผลสอบ:** หน้าสรุปแสดงคะแนน/สถิติที่ผู้ดูแลอนุญาต ผลเบื้องต้นอาจเปลี่ยนเมื่อมีผู้สอบเพิ่ม ผลรับรองใช้ค่าที่เผยแพร่ล่าสุด หากขึ้น “รอทบทวน” ค่าที่รับรองเองยังคงเดิมระหว่างตรวจข้อมูลใหม่ เมื่อสอบหลายครั้ง อันดับอิงครั้งที่เลือกตามนโยบาย; ลิงก์ในบัตรอันดับพาไปครั้งนั้น คำตอบดิบไม่ถูกแก้ด้วยการนำเข้าคะแนนรับรอง

**เกียรติบัตร:** มีรายการแยกทุกครั้งสอบที่เข้าเกณฑ์ ค่าเริ่มต้นเลือกคะแนนดีที่สุด ใบกำลังสร้างรอคิวแล้วดาวน์โหลด PNG/PDF ต้นฉบับจาก Dashboard ได้ QR เปิดหน้าตรวจสอบสาธารณะซึ่งไม่แสดงชื่อ/อีเมล/คะแนน ผู้ตรวจกรอกชื่อจริงหรือนามสกุลตามใบเพื่อตรวจว่าตรงกัน การตรวจลายเซ็นยืนยันข้อมูลที่ server ลงนาม ไม่ได้ยืนยันว่าภาพ PNG ทุกพิกเซลไม่ถูกแต่ง เมื่อเปลี่ยนชื่อ ใบเดิมถูกถอนและมีแจ้งเตือนให้ดาวน์โหลด revision ใหม่

**โจทย์ประจำวัน:** ต้องออนไลน์และเข้าสู่ระบบ ส่งได้ข้อละสองครั้ง ผิดครั้งแรกอาจมีคำใบ้ตามที่ผู้ดูแลเปิด ทำถูกครบเพิ่มไฟสูงสุด +1 ต่อวัน หลายข้อที่ตอบครบแต่ยังไม่ถูกทั้งหมดจะรักษาไฟ; แก้จนถูกครบได้เพิ่มไฟ วันมีข้อเดียว ตอบผิดครั้งแรกแล้วออกยังไม่ถือว่ารักษาไฟ ส่งข้อสอบในคลังที่มีคำตอบอย่างน้อยหนึ่งช่องช่วยรักษาไฟได้ โจทย์เก่าปิดรับตอนเที่ยงคืนไทยและฝึกย้อนหลังได้โดยไม่เปลี่ยนไฟ ถ้าระบบขัดข้องและผู้ดูแลขยายเวลา หน้าโจทย์วันนี้จะมีแถบแจ้งให้แตะเพื่อทำโจทย์ของเมื่อวานต่อจนถึงเวลาที่ขยาย ผลนับเป็นไฟของวันนั้น

ไฟแสดง Current, Highest, สถานะวันนี้และสิทธิ์กู้ หากพลาดหนึ่งวัน กู้ได้ถึง 23:59 น. ของวันถัดไป จำนวนสิทธิ์รายเดือนตาม Current: 0–9 =3, 10–29 =4, 30–49 =5, 50ขึ้นไป =6 ใช้สิทธิ์แล้วลด Current ทำให้คงเหลือไม่ต่ำกว่าศูนย์ Highest ไม่หายเมื่อไฟเริ่มใหม่

**บทความ:** อ่าน/ค้นหาได้โดยไม่ล็อกอิน กรองบทเรียน/ข่าว ระดับชั้น วิชา หมวดและวันที่ได้ เขียน/ตอบความคิดเห็นต้องล็อกอิน ข้อความเสี่ยงรอผู้ดูแลตรวจ เมื่อมีคำตอบจะมีแจ้งเตือนพร้อมลิงก์ไปความคิดเห็นและปิดได้ครั้งเดียว

**ลบบัญชี:** ที่โปรไฟล์เลือกคงใบพร้อมชื่อที่ลงนาม หรือถอนใบและทำชื่อไม่ระบุตัวบุคคล อ่านขอบเขต consent แล้วพิมพ์ข้อความยืนยัน ระบบออกจากทุก session และเก็บหลักฐานที่จำเป็นตามนโยบายที่ Owner อนุมัติ

## ผู้ดูแล

**ประวัติข้อสอบใน Dashboard:** แต่ละรายการแสดงชื่อชุด ระดับชั้น (ม.1/ม.4) วิชาตามที่ตั้งไว้ในชุดสอบ ครั้งที่ เวลาเริ่ม/ส่ง รหัสการส่ง อันดับ และคะแนน ถ้าชุดไม่ได้ตั้งระดับหรือวิชาไว้จะไม่แสดงบรรทัดนั้น

**อันดับและสถิติ:** เลือกชุดสอบ สลับ Calculated/Official และกรองธงได้ ธงไม่ได้คัดผู้เรียนออกอัตโนมัติ เลือกหลายรายการ ระบุเหตุผล กดแสดงตัวอย่างก่อนรวม/คัดออก/override/import แล้วตรวจผลก่อนยืนยัน แก้ค่ารับรองเองไม่แก้ raw answers เลือก metric ที่เปิดเผยและเผยแพร่ Final ได้ตามสิทธิ์ ผลอัตโนมัติสร้าง revision เมื่อข้อมูลเปลี่ยน; override คงค่าพร้อมธงทบทวน ย้อน revision ได้โดยประวัติเดิมยังอยู่ เวลา offline ที่ยังตรวจรับไม่ได้ต้องตรวจจากหลักฐานแล้วรับรองเวลาใน Admin ห้ามแทนด้วยเวลาจากเริ่มถึงส่งแบบเดา

**ตรวจรับเวลาสอบ (STAT-05):** ในหน้าอันดับ ทุกรายการมีปุ่ม "ตรวจรับเวลา" ให้เริ่มจากรายการที่มีธงเวลายังไม่รับรอง หน้าต่างแสดงหลักฐานจากทุกแท็บ/ทุก stream: เวลาที่ใช้งานจริง เวลา offline ที่เบราว์เซอร์บันทึก จุด checkpoint และเวลาที่ server ได้รับ ระบบไม่รวมเวลาของหลายแท็บให้อัตโนมัติ กรอกเวลาสะสมที่รับรอง (วินาที ไม่เกินช่วงเริ่มถึงส่งที่ server บันทึก) พร้อมเหตุผลและหลักฐาน กดแสดงผลก่อนรับรอง แล้วยืนยัน ระบบบันทึก Audit คำนวณอันดับใหม่ และไม่รับหลักฐานใหม่ของครั้งนั้นหลังรับรอง ตรวจได้เมื่อการสอบสิ้นสุดแล้วเท่านั้น

**บทความ:** สร้าง Lesson/News เลือกหลายระดับ/หลายวิชาโดย URL เดียว เพิ่ม text/rich text/list/quote/code/callout/math/table/image/video/columns/button/attachment ได้ ตารางใช้ rowspan/colspan และลบช่องที่ถูกรวม ภาพมี alt/caption/width/alignment มี media library และแนบ PDF/Office ที่ผ่าน validation พรีวิว desktop/mobile ก่อนส่งตรวจ Author ทำ draft ของตนเองและส่งตรวจ ผู้มีสิทธิ์ approve แล้ว publish หรือ schedule เวลาในอนาคต การแก้ draft ของบทความที่เผยแพร่ไม่เปลี่ยนฉบับ public จนอนุมัติใหม่

หมวดอยู่หน้า CMS: สร้าง/แก้ชื่อ/เปลี่ยนหมวดแม่/ลำดับ ลบได้เฉพาะหมวดที่ว่าง รวมหมวดผ่าน preview และต้องไม่รวมหมวดแม่เข้า descendant ตั้ง synonyms คำที่ต้องตรวจ และลำดับ/เปิดปิด/บทความแนะนำหน้าแรกจากหน้านี้ได้ URL slug เก่ามี redirect เมื่อลบฉบับที่เคยเผยแพร่ตอบ410

**ความคิดเห็น:** ดู thread, approve/reject/hide/delete พร้อมเหตุผล ตอบแล้วระบบแจ้งเจ้าของข้อความ เฉพาะข้อความที่อนุมัติแล้วแสดงสาธารณะ

**Daily:** สร้าง/คัดลอก/กำหนดวันที่หรือเข้าคิวสำรอง วันที่ตรงมีสิทธิ์ก่อนคิว ถ้าไม่มีโจทย์เลยระบบรักษาไฟอัตโนมัติ นำเข้า CSV/XLSX จาก template ที่ดาวน์โหลดในหน้า Daily ตรวจ preview ก่อน commit แก้เฉลยเก่าต้องดูผลกระทบและเลือกคง Current Fire/คืนจำนวนครั้งตามต้องการ การชดเชย outage ใช้ preview+reason และมี Ledger/Audit ย้อนตรวจ มีสี่วิธี: รักษา (ไม่เพิ่มไม่เสีย), กู้ให้ทั้งหมดโดยไม่ใช้โควตา, ชดเชย +1 ต่อวัน และขยายเวลาปิดรับโจทย์วันนี้ (เลือกได้เฉพาะก่อน 23:59:59 น. ของวันนั้น ขยายได้ไม่เกิน 24 ชั่วโมง ระหว่างนั้นเฉลยยังไม่เปิดและยังไม่เข้าคลังย้อนหลัง)

**Owner:** มอบสิทธิ์เฉพาะ module ที่จำเป็น เก็บ Owner สำรองอย่างน้อยสองบัญชี ดู actor/reason/revision/request/source ใน Operations อนุมัติ retention แยกประเภท (technical_logs และ learning_events ถูกลบอัตโนมัติเมื่อเกินจำนวนวันที่อนุมัติ หมวดอื่นบันทึกนโยบายไว้ ไม่ลบเอง) จัดการ signing keys และใช้ runbook กู้คืน ห้ามแชร์ตารางผลรายบุคคลต่อสาธารณะ; หาก Owner ทำภาพเผยแพร่ต้องปิดข้อมูลส่วนบุคคลเอง
